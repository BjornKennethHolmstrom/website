## Best tools for this layer

### Option A — Python (best for research/prototyping)

Use:

* Python
* Mesa (agent-based modeling)
* NetworkX
* NumPy/SciPy
* PySD or BPTK
* JAX if you want advanced dynamics later

Advantages:

* fastest iteration,
* easiest experimentation,
* huge scientific ecosystem,
* great for formalizing theory,
* ideal for papers/research.

Disadvantages:

* weak UX,
* hard to democratize directly.

---

### Option B — Julia (best for serious scientific simulation)

If the project becomes very serious:

* Julia is incredible for dynamical systems.

Advantages:

* extremely fast,
* ideal for nonlinear systems,
* differential equations,
* large-scale simulations.

Disadvantages:

* much smaller ecosystem/community.

I would not start here unless you already know Julia.

---

### Option C — NetLogo (surprisingly powerful)

Excellent for:

* agent interaction,
* emergence,
* educational simulations.

Could actually be amazing for early prototypes.

But:

* eventually too limited.
