## Abstract

Paper XIX motivates a distinction between descriptions of model behavior and the cost of changing a trained model. This sibling paper examines that distinction using recurrent predictors of a bouncing dot across four regimes. The historical geometry panel uses squared prediction dissimilarity, not the RMS loss-profile distance stated in the original text. The squared quantity is symmetric but need not satisfy the triangle inequality; its RMS root is a pseudometric on models [R]. The first connected threshold is exactly the minimum-spanning-tree bottleneck, which can reflect scale and arrangement.

The recovered twenty-zoo geometry panel does not meet the specified criteria for large reshaping, regime-dependent bridge rankings at registered slack, or a repeatable topological jump. These bounded failures are not proofs of invariance or absence. The scale spread is 1.721; threshold dependence of graph centrality remains evident. Exploratory RMS re-scoring of the first two tests changes no verdict.

A separate ten-seed panel measures fixed-budget adaptation using a capacity-matched reference. The cost proxy is directed and asymmetric, but the reference is not certified converged and the loss is evaluated on different samples from the reference. The registered distance-prediction test fails (median Spearman correlation 0.468); a post-hoc source–regime aggregation gives 0.544. The v4 summary's relative asymmetry is 0.763; exploratory restrictions to cap-limited references or positive costs retain substantial asymmetry. Selected staged adaptations outperform the specific equal-step home-warmup control under the cost proxy. The harder-reform and waypoint tests fail, and the staging mechanism is unresolved.

The constructive object is a typed adaptation system [R]: behavioral dissimilarity describes model pairs, whereas update-relative cost concerns a model state and a target task. Actual staged updates compose and their stipulated leg costs add; canonical-reference cost tables need not represent these paths. Directed path geometry on enriched states is not excluded. Institutional interpretations remain hypotheses [IP/H].
