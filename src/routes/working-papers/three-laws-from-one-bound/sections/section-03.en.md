## 3. Ashby as a deterministic counting bound — the First Law [R]

Fix a nonempty set of environmental conditions $W$ and an action set $A$. For each $w\in W$, let $A(w)\subseteq A$ be the nonempty set of actions adequate for that condition. Define task-relevant environmental variety $V_A$ as the minimum cardinality of a set of actions $S\subseteq A$ such that $S\cap A(w)\ne\varnothing$ for every $w\in W$. Assume a finite such cover exists; if none exists, no finite deterministic controller can be adequate in every condition. This is a property of the task and available actions, not the number of raw world-states or the controller's current partition. When every condition has exactly one adequate action, it reduces to counting distinct required actions. With overlapping adequate-action sets, pairwise comparisons need not suffice: three conditions allowing respectively $\{a_1,a_2\}$, $\{a_2,a_3\}$ and $\{a_1,a_3\}$ can each be served in pairs by a common action, but no single action serves all three. Here $V_A=2$.

A deterministic controller with $N$ distinguishable internal states assigns one action per state and therefore uses at most $N$ distinct actions. If it is adequate in every condition, the set of actions it uses covers all conditions by the definition above. Thus $N\ge V_A$ is necessary. This is a deterministic, zero-residual-inadequacy special case of requisite variety, not a derivation of Ashby's general law, which also allows partial regulation. The argument is a near-definitional counting bound; its value here is placement rather than novelty.

Three requirements matter. **Distinguish enough** — the bound $N\ge V_A$ is a necessary capacity condition. **Distinguish the right things** — for each occupied representation cell, all conditions in that cell must share at least one adequate action, and the policy must select such an action. Having enough internal states does not guarantee either property. **Revise distinctions or responses when the task changes** — novel stress can change adequate-action sets or introduce new conditions; the old partition or policy may then cease to be adequate, whether or not $V_A$ rises. Spare internal states can provide capacity for revision, but do not guarantee an appropriate partition or response. If no feasible action cover fits the available capacity, the controller must enlarge that capacity, change the task or accept residual inadequacy. Paper XIX proposes sensing and adjustment roles for this task. The counting argument does not establish that a particular role decomposition or translation mechanism is necessary; those are separate architectural hypotheses.
